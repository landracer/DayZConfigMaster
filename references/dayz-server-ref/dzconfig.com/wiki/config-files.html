Reference Guide XML / JSON / CFG

Configuration Files Overview

Complete reference guide for all DayZ server configuration files. Understand the purpose, format, and location of each file to effectively manage your server.

DayZ servers are configured through a collection of XML, JSON, and CFG files located in your server's mission folder and profile directory. Each file controls a specific aspect of the server — from loot economy and weather to player spawns and server settings. This page provides an overview of every configuration file and links to detailed documentation for each.

Core Economy Files

types.xml XML

Master item database. Defines every spawnable item with nominal counts, lifetimes, restock rates, and spawn flags.
cfgeconomycore.xml XML

Core economy mechanics including event triggers, loot respawn logic, and global economy parameters.
globals.xml XML

Global server variables: cleanup timers, animal/zombie counts, and world-wide settings.
cfgIgnoreList.xml XML

Items excluded from the economy system. Prevents specific items from spawning without removing type definitions.

Events & Dynamic Content

events.xml XML

Dynamic world events: helicopter crashes, contaminated zones, police cars, and supply drops.
cfgeventspawns.xml XML

Spawn positions and loot definitions for events. Works alongside events.xml.
cfgEffectArea.json JSON

Environmental effect zones such as contaminated areas with location, radius, and active effects.

Gameplay & Mechanics

cfggameplay.json JSON

Advanced gameplay mechanics: player health, stamina, disease systems, vehicle damage, and AI behavior.
cfgweather.xml XML

Weather patterns, rain, fog, wind, and lighting configuration.
cfgenvironment.xml XML

Environmental settings, lighting, and world parameters including ambient effects.

Spawns & Locations

cfgplayerspawnpoints.xml XML

Player spawn points and locations for new and respawning players.
cfgrandompresets.xml XML

Random loot generation patterns and presets for varied item selections.
cfgspawnabletypes.xml XML

Item spawn configurations and attachment spawning for weapons and equipment.
cfglimitsdefinition.xml XML

Spawn limits, categories, usages, and value tiers mapping to spawn point definitions.

Server Configuration

serverDZ.cfg CFG

Main server configuration: server name, passwords, player slots, network ports, and mission template.
Server Start .bat BAT

Batch script for launching your server with parameters, mod configurations, and startup options.

Messages & Economy Init

messages.xml XML

Server messages, notifications, and MOTD for player communication.
economy.xml XML

Economy initialization file that references all other economy configuration files.
