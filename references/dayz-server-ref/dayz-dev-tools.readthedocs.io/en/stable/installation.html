Installation

DayZ Dev Tools is listed on PyPI. I highly recommend installing it using pipx for command line use:

pipx install dayz-dev-tools

It can also be installed with pip or using your preferred Python package manager.

pip install dayz-dev-tools

DayZ Dev Tools can be run on Windows or Linux but Python 3.10 or higher is required.
