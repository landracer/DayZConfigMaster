proto native int GetMouseState ( MouseState index)

Returns state of mouse button.

It's combination of number of release/pressed edges and mask MB_PRESSED_MASK that is set when button is pressed. If you want just to check if button is pressed, use this: if(GetMouseState(MouseState.LEFT) & MB_PRESSED_MASK)) Print("left button pressed");
