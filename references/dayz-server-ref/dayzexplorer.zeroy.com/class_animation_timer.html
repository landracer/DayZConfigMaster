Detailed Description

AnimationTimer class.

This timer is for animating float value.
usage:

class MyObject
{
ref AnimationTimer myAnim;
void MyObject()
{
myAnim = new AnimationTimer();
myAnim.Run(60, this, "Refresh");
}
void Refresh()
{
Print(myAnim.GetValue());
}
};
